# TJN fixed registry RC1

Canonical nominal registry: `registry.json`, release `20261111-rc1`, 1234 cells (L4 466/L5 768).

Coordinates and IDs are stable in subsequent appends; new cells require a new release identifier. This is a candidate instrument geometry, not a certified usable-mask/template release. Nominal boundaries are defined exactly by the included TAN recipe and `targeted_observing.fixed_fields.boundary`; no external file is required to reconstruct them.

Full CSV/FITS, dense boundaries, daily/temporal membership and figures: `targeted_observing/products/tjn_fixed_20261111/`. Compact report: `targeted_observing/docs/tjn_fixed_20261111/REPORT.md`.

Object IDs must be read as strings, including numbered objects and `2014 ET220`. Field cloud prefixes are planning labels, not permanent object classifications. Masks and template common regions remain null until measured.
