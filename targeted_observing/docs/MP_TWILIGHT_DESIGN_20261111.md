# MP 晨昏模式：条带选场与实时曝光设计

状态：用户确认的约束及曝光可行性评估；尚未替换执行器或重跑年度。仅本地研发/GitHub，不部署生产。

## 已确认约束

- 只使用1855场生产MP原表，保留ID、坐标及角点；暂不增加外围黄纬天区。
- 晨昏高度下限25度，沿用足迹及全曝光验证语义，中心留足边缘余量。Trojan的高度限制独立保持原值，不以全局参数误改。
- 近太阳优先；相近日距角也可成组，偏好赤纬相近，不要求等高度。移除旧50–65度偏好和固定45度下限，按几何可达范围、月距、曝光可用性选场。
- 每场目标5次、最低3次，单一方案；8分钟重访为初始设计目标，场数由时间和几何可行性决定。已启动场先完成复访，再引入新场。
- 保留当前速度下限，不降低。仓库run_single_night.sh实际vmin=3 arcsec/h；LINEAR_NIGHT_SPEED=5是两段速度差容差，不是目标速度下限。63 arcsec/h上限改为配置，750为待注入验证的晨昏上限初值；不把范围放宽等同于真实高速目标检出能力。

## 路线设计

先筛逐曝光高度/月距/太阳距角与可用曝光的场，建立不同长度的近Dec/近距日角条带。对小场组枚举访问顺序及起始场，计入轮间回跳、进入/退出场组的开销，在到期复访约束下优化总时间；与原RA顺序比较，仅在同一组和相同约束下可声明路线耗时更优。优先近太阳的可完成组，条带规则是偏好而非强制单轴。

T_slew = 9.11 + max(11.95 sqrt(dRA), 12.30 sqrt(dDec))，度/秒，RA跨零、不乘cos(dec)。曝光和读出另加；读出与slew不重叠。同场无转场时不套用移动模型常数。实测读出均值14.47秒、调度保守预算15秒分别记录；正常转场公式与偶发时延分开。开销优化不得通过瞬间折返重复端点来破坏cadence。

## 实时曝光控制（待实现）

- 输入太阳高度、天区高度、相对太阳方位/距日角、月亮几何、滤镜及最近图像分块背景计数率，预测下一曝光起止间的背景。不能只把上一场背景直接复制给下一场，也不能等8分钟后同场复访才更新。
- 对偏置/暗电流校正后的图像分块估计背景，屏蔽源、坏像元、光晕和饱和区；保存代表值、高背景分位、梯度及质量标志。有限天空梯度不能通过全图中位数掩盖。
- 标定模型预测几何随时间的变化；最近有效帧更新当夜偏差及变化速率。晨间采用预计曝光结束时更亮的背景或曝光积分预测，避免反馈滞后。异常/过期反馈不能用于放宽曝光。
- −18<h_sun≤−10：选不超过30秒、且预计背景电荷未超相机线性预算的最长合法曝光。可写为 t≤Q_budget/B_pred，上述量分别为扣偏置后的安全背景ADU/pix和预测ADU/pix/s；实际算法还检查源峰值、梯度、拖线、读出及重访deadline。Q_budget须由本机线性范围标定，不能照搬平场的20000ADU目标。
- h_sun≤−18：正常科学曝光固定30秒；异常饱和/天气仍拒绝坏帧或停止，不用自动增加曝光补偿云。清晨越过−18后重新启用背景控制。
- 允许曝光时间在已验证的快门最短曝光至30秒间调整，不必只锁5/10/30三个档；最短值尚未标定。若所需曝光短于允许最短值，等待或选其他满足同一科学约束的MP场，不启动无法完成的序列。
- 背景上限仅防非线性，不保证检出深度；用星表零点/噪声估计有效深度并检查目标实际检出次数。无有效标定时仅生成模拟/测试输出，不把文献先验当实时反馈。
- 中点优先实际EXPSTA/EXPEND；次选经过语义核验的开始时间+实际EXPOSURE/EXPTIME/2，排查全链路固定15秒假设。跨午夜、5/10/30秒、缺字段与异常header必须测试。
