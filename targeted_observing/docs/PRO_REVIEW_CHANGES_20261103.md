## 数据与科学证据

- `python3 -m targeted_observing.review_data` 下载/读取 TESS `J/A+A/693/A66/tess` 和 Hipparcos `I/239/hip_main` 的 V<6亮端补表。原始表存cache，URL/hash及60候选的TESS证据在 `data/review_sources_20261103.json`。
- TESS核验9912行、9868个编号对象、44个临时编号、34个零宽区间；全部满足绝对上下界及完整宽度关系。与冻结TJN交集52、60候选命中7、5核心均未被本表收录。
- 保留18个原字段、会合周期、绝对上下界、完整区间宽度、备选周期及来源依赖。`e_Per`不是±1σ；零宽不是无限精度；未收录不是无周期。22180仍是弱约束对象，不把29.511小时当精确已知周期。
- DAMIT现在参与统一周期证据清单和差异检查。数值差异仅触发核查理由，不自动增加优先级；已有模型暂列known_other，未查充分列literature_unchecked（显式低权重0.1）。alias_review/slow_candidate必须经过人工文献判定，当前自动分类不冒充已完成此判断。

## 亮星风险

新 `bright_stars.py` 合并4992条Hipparcos V<6记录与已有Gaia区域缓存；Hipparcos坐标按自行线性传播到规划年代，V与G保留不同波段。足迹外扩2°用于提示散射光风险；缓存Gaia只覆盖原区域，不能宣称备选场完整无污染。

参宿四（HIP 27989）确实在原主场。按原三夜计划曝光中点、传播后的Hipparcos坐标，18054最近距离约21.52′、17.85′、10.57′；与GPT Pro使用不同坐标历元得到的21.53′、17.86′、10.58′一致到角秒尺度。本报告不把白天的小时星历极小值当作夜间访问值，也不根据未标定半径自动丢弃曝光。每个目标/夜/亮星有逐访问距离和待实测状态；移动场中心不能改变天体与恒星的真实角距。

## 调度修改

- 晨昏A/B先独立产生候选，再联合比较组数、总保留锚点数、前瞻可用夜数与扩展模式；初次选场前瞻第1、3天的实际访问，后续优先旧场与0.15/0.3/0.45°局部球面替换。是有限候选搜索，不宣称全局最优，也不把预测可用夜当晴夜。
- 原11/04场表回归到11/06可保留7/8；坐标由搜索产生，没有硬编码审查报告中的替代坐标。保留独立曝光审计、3.5°闭合转场、A/B间距和内外顺序；每组记录备选、替换ID及原因。
- Trojan移除固定22点截断，完整轮次按曝光/读出/实际转场和截止装入预算；75/89分钟单场分别30/36点。双场基线仍20点/场、330.88秒重访。
- ≥80%留场的分母统一为冻结campaign中**该场的计划曝光中点数**，不是14天所有小时点。候选设计先宽松预筛，再对14夜真实排程计算；调度输出逐帧在场状态，独立验证以当前夜替换campaign对应夜后重算。保留几何点数/覆盖夜数，测光可用率为null，等待图像；几何80%不替代高度/太阳/月距硬限制。
- 晨昏减至2–3场仍未启用，维持4场×5访；因此不会引入无等待的两场快速循环。本轮没有声称已实现所有v0附件的扩展接口、数字ID或恢复队列。

## 复现与现场边界

```bash
python3 -m targeted_observing.review_data
python3 -m targeted_observing.compare_campaigns
python3 -m targeted_observing.review_run
python3 -m unittest discover -s targeted_observing/tests -v
```

需要原有 `fetch_sources` 得到的文献/IERS及JPL目录。`compare_campaigns`会按版本化60候选补齐缺失星历；`review_run`产生3组×3夜计划，并独立审计3组×14夜Trojan块。产物在 `products/pro_review/`，不提交运行文件；源码、审查原文、小型科学输入、来源hash同步GitHub。

首轮现场仍需短曝光+r120检查星晕/背景、稳定星误差—星等、真实转场/稳定时间及有效点率。未连接服务器，未执行望远镜操作；没有真实图像，不能填报实测污染半径、r精度或科学产率。
