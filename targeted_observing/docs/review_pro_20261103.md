### 2. 已经核验了全表，接入时最容易误读的是误差

完整导出有 **9,912 行、18 个原始字段**。其中 9,868 行有唯一 MPC 编号，44 行保留临时编号。

我对实际数据逐行核验了这些关系：

\[
b\_\mathrm{Per}\leq \mathrm{Per}\leq B\_\mathrm{Per},
\qquad
e\_\mathrm{Per}=B\_\mathrm{Per}-b\_\mathrm{Per}.
\]

因此：

| 字段 | 正确处理 |
|---|---|
| `Per` | 主周期，小时，保留会合周期的来源标记 |
| `b_Per`、`B_Per` | **绝对区间下端与上端** |
| `e_Per` | **完整区间宽度，不是 ±1σ** |
| `PerOthers` | 其他候选周期，原文和解析数组都保留 |
| `sigmaValue`、`sigmaThreshold` | 拟合统计量，不能直接改成 LCDB U |
| `e_Per=0` | 有 **34 行**，单独标记，不能解释成无限精度 |

这份表没有一个可以不加解释、直接套用的 LCDB 式统一可靠等级。数据包保留了原字段，并增加了可检查的派生标记，没有把它们压成一个“可靠/不可靠”的黑箱分数。
