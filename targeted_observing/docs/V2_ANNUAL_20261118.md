# v2 共用场全年回放与产额口径

本轮模拟使用服务器的 `server_scheduler.build`，年份为2026-11-01至2027-10-31，共365个北京时间观测夜。4397场共享表及MP/TJN前缀、独立YSO、18秒读出、24秒切片和两轴转场公式均与生产一致。没有预设未来后随命令。模拟不发布观测列表、不写生产实拍历史、不调用MPC。

晨昏一小时为优先目标。整小时路线不可行时，在原窗口内尝试延后0–30分钟的3–5次访问短路线，保持5–12分钟复访、全视场高度、太阳距和月距条件；仍不可行则跳过该段。TJN接续的候选块截止不晚于天文晨光，避免用过亮的未来时段否决前面的可用暗夜。晨昏选场以|HA|<4.95h留余量，最后以HADec核验5h参考边界；这不代替机械编码器认证。

## 输入与因果反馈

目标集是已有1063颗冻结TJN年度候选，不代表总体完备样本。使用已有6小时站心Horizons星历、冻结IERS、候选云团分类和文献周期/科学角色证据。每个情景从零测量历史开始；没有把11月后半的实拍记录倒灌到11月初。

每夜先读取该情景此前实际模拟到的检出和质量点选场，再实现当夜天气及测光。整个科学列表中的MP、TJN、YSO曝光均检查候选的实时时刻TAN落场，计入相应检出；只有r点用于现有r光变采样门槛。队列看不到未来天气。

晴夜基准1条；基准测光16条、乐观8条、保守8条天气路径，共33条年度路径。各测光情景共享同编号天气，便于比较；统计给P10/P50/P90，表示这些实现中的分布，未覆盖未知总体参数的不确定性。

天气采用仓库 `weather_prior.json` 的六年逐月历史可观测夜比例，2026-11-18已与[原始期刊表3](https://academic.oup.com/view-large/337462686)逐值核对。Observable包括部分多云，不等同精密测光夜。AR(1)相关、额外15%时段损失、局部云、延误、读出/转场抖动和视宁度参数是规划情景，不是本台实测拟合值。

测光沿用 `annual_defaults.json`：暗天顶r=18、120秒的随机误差标度分别0.015/0.025/0.04mag，加0.005mag底噪；夜零点0.008/0.012/0.02mag，可用点比例0.95/0.85/0.70。随星等、气团、月亮、视宁度和曝光时间变化。用V近似r，其余波段也暂用同星等近似；检测采用约5σ深度附近的平滑概率曲线。静态列表的累积硬件延误会推进实际时刻并重新检查几何。

## 三种不同结果

- 检出：至少一次有效测量的不同TJN数量，并另给总测量次数、r检出对象和r测量次数。
- 采样就绪：生产同一套点数/夜数/连续跨度/最大间隔/基线/误差/先验相位覆盖条件。每夜至少5点、跨度≥30分钟、最大间隔≤30分钟，总计100个合格r点、10夜、21天基线及0.03mag中位误差等；有先验时还需更长基线和相位覆盖。首次达标保存证书及对应真实模拟时刻。
- 周期回收：在证书对应的时刻上注入光变并盲搜，不直接把采样就绪数当作周期数。使用误差、相关夜零点、观测者至发射时刻光行时修正，以及非对称/对称双峰/复杂形状混合。

振幅分别0.1/0.3/0.6mag；有文献时从冻结备选周期选取，无资料时按每个对象固定的示例log-uniform 2–1000h生成。周期统计限2–1000h，要求相对真值误差<1%，分离候选和±1%周期替代的Δχ²均≥9。唯一性是搜索启发式，不是校准后验概率。另报可靠既有先验附近±5%搜索；它与盲搜计数重叠，不能相加。弱/未查全先验组单独计数，不据目录缺失宣称新发现。

## 加速与验证

`annual_v2.py`只放临时工作区运行；`annual_v2_fast.py`用Numba编译原路线逐曝光公式，并批量缓存YSO的原生标量评分。生产不导入Numba。`requirements-annual.txt`列出该离线依赖。

全年每夜的晨昏路线都做原生直接几何验证；整晚沿用生产最终验证器，天空量取同一Astropy 60秒网格插值，HADec时角仍直接计算。晴夜每30晚另做原生直接整晚核对和插值误差审计。已对普通及短时晨昏代表夜比较原版/缓存版全部天区、曝光、模式、目标ID和开始时刻；每case每7晚保存带模型hash的检查点。

`annual_v2_delivery.py`核对33条完整365夜、日期唯一性、同一模型hash、曝光计数闭合和周期计数上界后汇总。动图逐夜累计共享场曝光次数，使用全年固定log色标；灰色为零，MP/TJN按四位ID合并，YSO独立。左为晴夜基准，右为基准天气路径0，不代表全年平均天气图。

## 执行与清理

在默认服务器通过Slurm运行，典型资源33 CPU/128GB，并限制每进程BLAS/OMP为1线程。把 `annual_v2.py`、`annual_v2_fast.py` 和 `data/weather_prior.json` 投到新建临时根；天气文件保持 `临时根/data/weather_prior.json`。静态生产缓存只读。

```bash

sbatch --cpus-per-task=33 --mem=128G --time=02:00:00 \
  --output="$task_run/year.log" \
  --wrap="env PYTHONPATH=/pipeline/xiaoyunao OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/smtpipeline/Softwares/miniconda3/bin/python -u $task_run/annual_v2.py $task_run/full --workers 33"
```

结果校验、制图和下载后核对SHA256，确认所有本次作业结束，再删除整个本次临时根。几何缓存、Numba缓存、检查点、失败日志与烟测产物不留在服务器。保留交付GIF/PNG、逐场CSV、33路径汇总、光变/周期参数及验证记录于本地输出目录。运行结果和清理凭证见 `WORKLOG.md` 最新记录。
