# TJN 固定监测天区：2026-11-11 候选发行版

**已完成全年轨迹支持的名义固定场划分；状态为 RC1，尚未正式冻结为仪器认证场库。** 实测 TPV 模型检查通过，但真实坏像素/渐晕遮罩、模板公共裁边和高低赤纬重复指向/PA 分布尚缺。今晚控制脚本及既有生产代码保持原状。

这些范围仅为分离区域的外包络，不能当成满铺矩形。每晚只取其中少量场。静态注册表不写目标名单；逐时归属另外保存。

采用 RA/Dec=0°锚点、Dec 行距 **2.50°**，同行 `N=ceil(360*cos(Dec)/2.50)`、`RA=k*360/N`。相机设计轴约定为 +x 北、+y 东，PA=0°，宇称 −1；这是一项长期几何约定，硬件实际 PA 仍需标定。

原建议 2.67264°/2.67496°节距在保守 TAN 模型下，保留单侧 0.15°测光留边和 0.01°轨迹余量后，18,314/534,753 个可见采样点（3.42%）即使允许邻场也无法进入安全区。故在首次定版前整体缩小节距；没有移动任何已正式冻结的旧场。未优化全局相位，保留建议的零锚点。

采用 9216×1.15″=2.944°的保守内接正方形；不把约 3°、1.16″、9232/9224 像素口径混用。逐行每边 2,049 点，最小名义留边 11.360′，超过所需 9.6′。旧 `in_field(... margin=.15)` 是移动目标质量条件，并非实测模板裁边。

## 实测 WCS 的证据范围

恢复本地 4 个历史场的 12 份完整 TPV WCS，裁剪 CRPIX 加回裁剪原点。目录 X_Win/Y_Win 从1起算，转换为0起算后重投影误差≤4.7e-10像素。每份边缘1,028点正反变换通过。像元尺度约1.155″，+x PA约−0.336°至−0.271°，+y向东，宇称−1。

将这些完整畸变模型平移到所有候选行的情景检查，最小边缘余量 593.4像素，超过约500.9像素的0.16°要求。这些原始样本实际赤纬仅约−3°至+8°，不能冒称高赤纬硬件PA和模板遮罩已经实测通过。`in_usable`/`usable_mask_ref` 保留空值，正式冻结状态明确为 false。

使用完整 [Astropy WCS 变换](https://docs.astropy.org/en/stable/api/astropy.wcs.WCS.html)，而非只凭四角或RA–Dec外包矩形。
