# 晨昏 + 木星特洛伊本地模式：目标与验收

建立日期：2026-11-03。范围来自当日本聊天授权及引用对话的最新完整问答。
本轮允许新增独立子目录，优先于旧 AGENTS 的“三套正式目录”限制；新增目录是本地研发模式，不是服务器镜像或 survey 的平行副本。

## 当前目标

在 `targeted_observing/` 交付能真实选场、生成计划、独立验收的 Python 模式；冻结当前季节两个 Trojan 场，生成 11/03、11/04、11/06 三夜草案及冬至/春分/夏至/秋分模拟。同步 GitHub 专用分支，不连接服务器、不改变生产调度、处理或 MPC hold。

## 参数和实施选择

- 站点：117.575°E、40.393°N、960 m；北京时间夜次，内部 UTC；无折射。
- 晚窗：太阳下降到−12°起60分钟；晨窗：太阳上升到−12°前60分钟。
- 每侧两个半小时槽，A小太阳距角、B大太阳距角；清晨 B→A；槽内余量不填不完整组。
- 固定 r；30/120秒曝光；15秒读出；实际换片10秒；进入块按未知上一指向预算60秒。
- 转场采用 `max(20或60秒, 9.24145 + max(11.92277√ΔRA,12.22922√ΔDec) + 2秒)`，相邻阈值3.2°。现有30夜header正常分支提供下限，非控制器最坏时延保证。
- 几何：中心≥32.5°，全足迹>30°；月在地平线上时30°避月，照明≥75%时40°；用包围整个足迹的球面角帽保守校验。
- 默认2小时 Trojan 块，保留5分钟交接；22点为上限，按实际转场预算减少；不承诺每场22点。
- 日间固定场选择先用二体/H–G近似粗筛，再对排名60个候选用每小时站心星历严格留场；不是全局最优解或完备样本。
- 优先复用整个晨昏组，再尝试3个旧场+1个新场；不能达标时记录保留数，不绕过几何限制。
- 外部预约仅提供时间区间输入；YSO/SN/public 具体科学队列不在本轮范围。
- r 指令 token 尚无现场证据：可执行 TXT 默认拒绝。可选导出也仅生成分块 `.draft.txt`，TXT 无时间指令；不能凭文件存在部署。

## 科学判定和首轮观测

三有效夜用于确认执行完成率、r30/r120性能、实际转场/读出、按亮度分档的稳定恒星重复误差、跨夜零点、候选恢复率及目标留场。没有新NEO或唯一周期不构成首轮失败。

4–6周争取10–14有效夜；第10有效夜或第4周复盘；14天后显式更新场版本。慢转不能逐夜去均值；保留光行时、相角、距离和多种周期别名。

## 不作为本轮完成条件

- 服务器部署、现场采集、控制token确认和实际三有效夜反馈。必须有后续授权与现场输入。
- 改造快速NEO检测或直接恢复 MPC 上报。当前3–63角秒/小时轨迹范围不证明适合高速目标。
- 完成全世界全部周期文献搜查、无偏发现率预测、场景完备性或长期轨道共振积分。
